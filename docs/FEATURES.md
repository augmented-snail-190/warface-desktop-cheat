# Warface Desktop Toolkit — feature reference

Warface Desktop Toolkit brings display options and profile groups into one section-based interface. Shortcut reference provides the third part of the workflow.

| Section | Description |
|---|---|
| Display options | Display or performance-related options, with space for configuration and comparison information. |
| Profile groups | Related settings collected into named groups for a clearer configuration workflow. |
| Shortcut reference | Shortcut assignments and control mappings, organized in one reference section. |

The project page follows the same section structure.
